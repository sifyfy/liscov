# デザイントークン

更新: 2026-10-08 (合意: 2026-10-08)

画面で使う値 (色・文字・余白・角丸・影・動き) の閉じた集合。画面のコードは、ここにある「意味」の層の名前だけを使う。
値の理由は [ブリーフ](brief.md) の節か、参照した規則 (Material Design 3) から引く。形容詞を理由にしない。

## 構造

Material Design 3 にならい 3 階層にする。各層は 1 つ下の層だけを参照する。

1. **値** (`--ref-*`): 色の値、サイズの数列。画面のコードからは使わない
2. **意味** (`--sys-*`): 役割の名前。画面のコードはこれを使う。ダークとライトはこの層で切り替える
3. **部品** (`--comp-*`): 部品ごとの値。必要になったときだけ作る

## 文字

### 書体

- 和文の可読性で選ぶ。書体で個性を出さない (ブリーフ §6「引き立て役」)
- **BIZ UDPゴシック** を使う (読み間違いを減らす UD 書体。数字と似た字形の区別が明確。太さは 400・700 だけ)。
  見本ページで現行の Zen Kaku Gothic New と並べて決めた (2026-10-08)。Zen Kaku Gothic New は数字が小さく線が細い
- 見出し用の欧文書体 (Plus Jakarta Sans) はやめる (使われすぎの書体で、和文と混ざる理由もない)
- 数字 (金額・件数・時刻) は等幅の数字 (`font-variant-numeric: tabular-nums`) にする。桁が揃い、変化を目で追いやすい
- 等幅の書体 (JetBrains Mono) は、ポート番号などの技術的な値だけに使う

### 段階 (アプリの UI)

| 名前 | サイズ / 行間 / 太さ | 用途 |
|---|---|---|
| `caption` | 12 / 16 / 400 | 時刻、件数の補足 (主な情報には使わない) |
| `label` | 13 / 18 / 700 | ボタン、タブ、ラベル |
| `body` | 14 / 20 / 400 | 設定の本文、説明 |
| `title` | 16 / 24 / 700 | パネルやダイアログの見出し |
| `display` | 20 / 28 / 700 | 画面にひとつの大きい数字 (同接数など)。使わなければ消す |

- 本文 14/20 と 12px の下限は、参照した慣習 (YouTube のチャット 14/20、Material 3 の body-medium 14/20) から。
  離れて見るので、11px 以下は使わない
- 太さは 400 と 700 の 2 つだけ (書体の制約と、段階を減らすため)

### 段階 (コメント)

コメントの文字は、利用者が設定する大きさ (`message_font_size`、10〜24px、既定 13px。[09_config](../specs/09_config.md)) を基準 `1em` にした比で決める。

| 名前 | 比 | 既定 (13px) での大きさ | 用途 |
|---|---|---|---|
| `chat-body` | 1em / 行間 1.45 | 13px / 19px | 本文 |
| `chat-name` | 0.85em / 700 | 11px | 名前。本文の上の名前の行に、読み仮名・#N・時刻と並べる (2026-10-10 に 1 行から 2 段に変えた。02_chat「1 行の形」) |
| `chat-meta` | 0.85em | 11px | 時刻・回数 (#N)。既定では控えめに |
| `chat-amount` | 1.15em / 700 / 等幅の数字 | 15px | スパチャの金額 |

- `chat-meta` が 11px になるのは既定の 13px のときだけで、利用者が大きくすれば一緒に大きくなる

## 色

### 面 (`--sys-surface-*`)

Material 3 の surface container の考え方。面の段階で入れ子と浮き上がりを表し、カードの枠や影を減らす。

| 名前 | ダーク | ライト | 用途 |
|---|---|---|---|
| `surface` | `#131315` | `#fbfbfc` | ウィンドウの地 |
| `surface-low` | `#18181b` | `#f4f4f6` | コメント一覧の地 |
| `surface-mid` | `#1d1d21` | `#eeeef1` | ヘッダー、帯 |
| `surface-high` | `#25252a` | `#e6e6ea` | 強調した行、マウスを載せた行、ポップアップ |
| `surface-highest` | `#2e2e34` | `#dedee3` | 入力欄 |

- 色相は持たせない (中立の灰色)。色相は強調のために空けておく

### 文字 (`--sys-fg-*`)

文字の段階は、色ではなく明るさの 3 段で表す (参照: YouTube の 100% / 70% / 54%)。

| 名前 | ダーク | ライト | 用途 |
|---|---|---|---|
| `fg-1` | `#ededf0` | `#1b1b1f` | 本文、名前 |
| `fg-2` | `#b8b8bf` | `#4a4a52` | 補足、ラベル |
| `fg-3` | `#8e8e96` | `#66666e` | 時刻、回数、控えめにするもの (優先順位 6〜8) |

- すべての面の上で WCAG 2 AA (4.5:1) を満たす。ただし `fg-3` は `surface-highest` (入力欄) の上では 4.2 前後になるので、入力欄には使わない
- コントラストは単体テストで確かめる (値を変えたらテストが落ちる)

### 線

| 名前 | ダーク | ライト | 用途 |
|---|---|---|---|
| `outline` | `#3b3b42` | `#c4c4cc` | 入力欄の枠、区切りを強く見せたいとき |
| `outline-variant` | `#2a2a30` | `#dcdce2` | 一覧の区切り線 |

### 強調 (優先順位 1〜4)

ブリーフ §2 の強調の段階を、色で表す。

| 優先順位 | 表し方 |
|---|---|
| 1 スパチャ・ステッカー | YouTube から届くティアの色をそのまま使う (トークンにしない。データとして扱う) |
| 1 メンバーシップ・ギフト・マイルストーン | `member` の色 (YouTube のメンバーの緑の系統) |
| 2 新規さんの初回 | `highlight` の薄い背景 (20%) + 塗りの印「初見」 |
| 3 新規さんの 2 回目以降 | 枠だけの印「初見」。**背景はつけない** |
| 4 常連の配信内初回 | 名前の前の小さい点 |
| 5 標準 | 色を持たない |
| 6〜8 | `fg-3` |

- メンバーのふだんのコメント (優先順位とは別): 名前を `member-text` の色 (ダーク `#4cc26a`、ライト `#13703a`) にし、
  YouTube のメンバーバッジの画像を名前の横に置く。背景や枠は付けない (YouTube の慣習。シフィさん、2026-10-09)。
  `member-text` はすべての面の上で 4.5:1 を満たす (単体テスト)。ただし優先順位 2 の薄い背景の上では足りないので、その行の名前は `fg-1` にする
- `highlight` の色はすみれ (ダーク `#b9a5ff`、ライト `#5f43cc`)。見本ページで空色 (accent と共用)・色相なしと並べて選んだ。
  スパチャのティアの色 (青〜赤) と被りにくい
- 2〜4 は、強調の要素の数で区別する (背景と印 → 印だけ → 点だけ)。3 に背景をつけると、2 と同じ要素の組み合わせになって
  強さの差だけになり、見間違えるおそれがある (見本を見たシフィさんの指摘、2026-10-08)
- ティアの色は文字の色も含めて YouTube のまま出す。オレンジのティアは白い文字で WCAG AA に届かない (見出し 3.78:1、本文 2.7:1) が、
  承知の上で YouTube に合わせる (シフィさん、2026-10-09)。読みやすさを調整する設定は未設計 (02_chat.md「未決事項」)
- YouTube のティアの色は青から赤まで色相のほとんどを使うので、`highlight` はティアと形で区別する
  (ティアは面の全面塗り、`highlight` は薄い背景と小さい印)
- `highlight` は印の文字や点として文字の役割も持つので、すべての面の上で 4.5:1 を満たす (単体テストで検査する)
- 優先順位 2 の薄い背景 (面に `highlight` を 20% 重ねたもの) の上では、文字に `fg-1` と `fg-2` だけを使う。
  `fg-3` は 3.9:1 (ダーク) まで下がる (試作の撮影で axe が検出、2026-10-08)。時刻・回数もこの行では `fg-2` にする。単体テストで検査する

### 操作と状態

| 名前 | ダーク | ライト | 用途 |
|---|---|---|---|
| `accent` | `#8ab4f8` | `#1757c0` | 選択中、フォーカスの輪、リンク |
| `success` | `#6dd58c` | `#186a31` | 接続中 |
| `warning` | `#f2c55c` | `#7a4f00` | 注意 |
| `error` | `#f28b82` | `#b3261e` | 切断、エラー |

- 状態の重ね色 (Material 3): マウスを載せたとき `fg-1` を 8%、押したとき 12% 重ねる
- 接続中は目立たせない。切断・エラーのときだけ目立たせる (ブリーフ §2)

## 余白

基準 4px。`0 / 2 / 4 / 8 / 12 / 16 / 24 / 32` (px)。

- 2px は、同じ人の連続したコメントの間など、近い関係を詰めるときだけ
- 関係の近いものは詰め、区切りは広く (同じ値を全部に使わない)

## 角丸

`4px` (入力欄・ボタン・小さい印)、`8px` (ポップアップ・ダイアログ)、`full` (アバター・丸い印) の 3 つだけ。
コメントの行には角丸をつけない (カードにしない)。

## 影

浮くもの (ポップアップ・メニュー・ダイアログ) だけに使う。2 段。色のある影・光は使わない。

| 名前 | 値 (ダーク) | 用途 |
|---|---|---|
| `elevation-1` | `0 2px 8px rgba(0, 0, 0, 0.4)` | メニュー、ポップアップ |
| `elevation-2` | `0 8px 24px rgba(0, 0, 0, 0.5)` | ダイアログ |

## 動き

| 名前 | 値 | 用途 |
|---|---|---|
| `duration-fast` | 100ms | マウスを載せたとき、押したとき |
| `duration-normal` | 200ms | 開く・閉じる |
| `easing` | `cubic-bezier(0.2, 0, 0, 1)` (Material 3 の standard) | すべて |

- バウンス・弾性は使わない。新しいコメントの出現に動きをつけない (引き立て役)。
  優先順位 1 のものが来たときだけ、目に入る動きを許す (内容は方向性 3 案で決める)

## 強制のしかた

- 画面のコードは `--sys-*` (と Tailwind に登録した名前) だけを使う。生の色値と Tailwind の任意値は lint で止める
- 仕組みは [design-lint.config.js](../../design-lint.config.js)。任意値・Tailwind の既定の値 (文字サイズ・角丸・影・色・書体・太さ・行間・字間)・
  生の色値 (JS の文字列、style 属性、`<style>`) をエラーにする
- 既存の画面は M5 (方向性 3 案からの作り直し) で書き直すので、一度に全部を直さない。既存の違反は ESLint の bulk suppressions で
  `eslint-suppressions.json` に記録して抑える (2026-10-08 時点で 27 ファイル・1,099 件)。記録はファイルごと・規則ごとの件数で、
  それを超える新しい違反はエラーになる。直して減ったら `pnpm lint:prune` で記録を減らす
- 移し終えたファイルは `DESIGN_MIGRATED` に足す。Tailwind に登録されていないクラスもエラーになる
- すべて移したら `eslint-suppressions.json` を消し、Tailwind の既定のテーマを消す (`@theme { --*: initial }`)
- コントラストは `src/lib/design/tokens.test.ts` で検査する
